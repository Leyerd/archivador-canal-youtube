Cuenta de Google

Necesario para ver tus videos privados y no listados.
Cliente OAuth: · quitar
Configurar acceso (una sola vez)
  1. Entra en Google Cloud Console y crea un proyecto.
  2. En APIs y servicios activa la YouTube Data API v3.
  3. En Pantalla de consentimiento elige Externo y añádete como usuario de prueba.
  4. En Credenciales crea un ID de cliente OAuth de tipo Aplicación de escritorio.
  5. Pega aquí el ID y el secreto, o carga el JSON descargado.
Si Google responde «Acceso bloqueado · invalid_client» o «The OAuth client was not found», el ID guardado no corresponde a ningún cliente real: pulsa quitar y pega el de tu proyecto.
